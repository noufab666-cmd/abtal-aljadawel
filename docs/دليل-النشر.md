# دليل نشر لعبة «أبطال الجداول»

هذا الدليل لكِ يا أستاذة نوف، ولا يحتاج إلى أي خبرة برمجية. كل خطوة فيه تتم بالضغط على أزرار في المتصفح.
يستغرق الإعداد نحو ١٥ دقيقة، ويتم **مرة واحدة فقط**.

نحتاج إلى خدمتين مجانيتين:

| الخدمة | لماذا نحتاجها؟ |
|---|---|
| **Firebase** (من Google) | لحفظ حسابات الطالبات ونتائجهن، حتى تلعب الطالبة من الجوال ثم تكمل من الآيباد |
| **GitHub Pages** | لنشر اللعبة برابط آمن يبدأ بـ https يفتح على أي جهاز |

---

## الجزء الأول: إنشاء قاعدة البيانات في Firebase

### ١) إنشاء المشروع
1. افتحي الموقع: https://console.firebase.google.com وادخلي بحساب Gmail الخاص بك.
2. اضغطي **Create a project** (إنشاء مشروع).
3. اكتبي اسم المشروع: `abtal-aljadawel` ثم **Continue**.
4. عند سؤالك عن **Google Analytics** أوقفيه (لا نحتاجه)، ثم **Create project**، وانتظري حتى ينتهي ثم **Continue**.

### ٢) تفعيل تسجيل الدخول
1. من القائمة الجانبية اختاري **Build** ثم **Authentication**، ثم **Get started**.
2. اختاري **Email/Password**، وفعّلي **أول مفتاح فقط** (Enable)، ثم **Save**.

### ٣) إنشاء حساب المعلمة (مهم: قبل مشاركة الرابط مع الطالبات)
1. في صفحة Authentication نفسها اختاري تبويب **Users** ثم **Add user**.
2. في خانة البريد اكتبي بالضبط:
   `teacher@abtal-aljadawel.app`
3. في خانة كلمة المرور اكتبي كلمة مرور قوية تحفظينها (٦ أحرف على الأقل). **هذه كلمة مرور لوحة المعلمة**، فلا تشاركيها مع أحد.
4. اضغطي **Add user**.

> هذا البريد ليس بريدًا حقيقيًا، بل اسم ثابت لحساب المعلمة داخل اللعبة. عند دخول لوحة المعلمة ستكتبين كلمة المرور فقط.

### ٤) إنشاء قاعدة البيانات
1. من القائمة الجانبية: **Build** ثم **Firestore Database**، ثم **Create database**.
2. اختاري الموقع (Location) الأقرب، مثل `me-central2 (Dammam)` إن ظهر، أو `eur3 (europe-west)`، ثم **Next**.
3. اختاري **Start in production mode**، ثم **Create**.

### ٥) لصق قواعد الحماية
هذه القواعد تمنع أي طالبة من رؤية نتائج غيرها أو تعديل نقاطها، وتسمح للمعلمة وحدها بمتابعة النتائج وإضافة الأسئلة.
1. في صفحة Firestore Database اختاري تبويب **Rules**.
2. احذفي كل النص الموجود، والصقي النص التالي كما هو:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    function signedIn() { return request.auth != null; }
    function isTeacher() { return signedIn() && request.auth.token.email == 'teacher@abtal-aljadawel.app'; }
    function isOwner(uid) { return signedIn() && request.auth.uid == uid; }
    function n(d, k) { return d.get(k, 0); }
    function newStudent(uid, d) { return d.uid == uid && d.team in ['stars', 'moons', 'pearls', 'flowers'] && d.name is string && d.name.size() <= 40 && d.totalScore == 0 && d.roundsPlayed == 0 && n(d, 'fullRounds') == 0 && n(d, 'certificates') == 0; }
    function okUpdate(uid, d, o) { return d.uid == uid && d.name == o.name && d.team == o.team && d.pin == o.pin && d.roundsPlayed == o.roundsPlayed + 1 && n(d, 'fullRounds') >= n(o, 'fullRounds') && n(d, 'fullRounds') <= n(o, 'fullRounds') + 1 && (n(d, 'certificates') == n(o, 'certificates') || n(d, 'fullRounds') >= 12) && d.totalScore >= o.totalScore && d.totalScore <= o.totalScore + 300; }
    function okRound(d) { return d.score is int && d.score >= 0 && d.score <= 300 && d.correct is int && d.correct >= 0 && d.correct <= 10 && d.answers.size() <= 10; }
    function student(uid) { return getAfter(/databases/$(db)/documents/students/$(uid)).data; }
    match /students/{uid} {
      allow read: if isTeacher() || isOwner(uid);
      allow create: if isOwner(uid) && newStudent(uid, request.resource.data);
      allow update: if isTeacher() || (isOwner(uid) && okUpdate(uid, request.resource.data, resource.data));
      allow delete: if isTeacher();
      match /rounds/{rid} {
        allow read: if isTeacher() || isOwner(uid);
        allow create: if isOwner(uid) && okRound(request.resource.data);
        allow delete: if isTeacher();
      }
    }
    match /leaderboard/{uid} {
      allow read: if signedIn();
      allow write: if isTeacher() || (isOwner(uid) && request.resource.data.total == student(uid).totalScore && request.resource.data.name == student(uid).name && request.resource.data.team == student(uid).team);
    }
    match /questions/{qid} {
      allow read: if signedIn();
      allow write: if isTeacher();
    }
  }
}
```

3. اضغطي **Publish**.

### ٦) الحصول على «إعدادات الربط» وإرسالها لي
1. اضغطي على رمز الترس ⚙️ بجانب **Project Overview** أعلى القائمة، ثم **Project settings**.
2. في الأسفل، عند **Your apps**، اضغطي على رمز الويب `</>`.
3. اكتبي أي اسم مثل `abtal-web`، ولا تختاري Firebase Hosting، ثم **Register app**.
4. سيظهر لك نص يبدأ بـ `const firebaseConfig = {` وفيه `apiKey` و`projectId`… انسخي هذا الجزء وأرسليه لي في المحادثة.

> هذه الإعدادات **ليست سرية**؛ فهي تُرسل إلى كل من يفتح اللعبة. الحماية الحقيقية في قواعد الخطوة ٥.

### ٧) السماح لرابط اللعبة
1. ارجعي إلى **Authentication** ثم تبويب **Settings** ثم **Authorized domains**.
2. اضغطي **Add domain** واكتبي: `noufab666-cmd.github.io` ثم **Add**.

المستودع يحتوي فقط على كود اللعبة والأسئلة، ولا يحتوي على أسماء الطالبات أو نتائجهن (فهذه محفوظة في Firebase ومحمية).

1. افتحي: https://github.com/noufab666-cmd/abtal-aljadawel/settings
2. انزلي إلى أسفل الصفحة حتى **Danger Zone** ثم **Change visibility** واختاري **Public** وأكّدي.

## كيف تستخدم الطالبات اللعبة؟
1. تفتح الطالبة الرابط من الجوال أو الآيباد.
2. تكتب اسمها ورمزًا سريًا من ٤ أرقام، ثم تضغط «ابدئي».
3. أول مرة فقط: تختار فريقها من أربعة فرق بأسماء علماء الرياضيات: الخوارزمي، البيروني، ابن الهيثم، الكاشي.
4. في المرات التالية تكتب الاسم والرمز نفسيهما من أي جهاز، فتدخل مباشرة إلى حسابها.
5. لإضافة اللعبة إلى الشاشة الرئيسية في الآيباد/الآيفون: زر المشاركة في Safari ← **إضافة إلى الشاشة الرئيسية**.

**نسيت الطالبة رمزها؟** ادخلي لوحة المعلمة ← نتائج الطالبات ← «التفاصيل» بجانب اسمها، وسيظهر لك رمزها.

**تغيير كلمة مرور المعلمة:** من لوحة المعلمة ← الإعدادات.

**نسيتِ كلمة مرور المعلمة؟** من Firebase: Authentication ← Users ← احذفي حساب `teacher@abtal-aljadawel.app` ثم أنشئيه من جديد بالبريد نفسه وكلمة مرور جديدة. لن تُحذف أي نتائج.

## قواعد اللعبة باختصار
- ٦ مجالات: جداول ٠ و١ و٢ و٤ و٥ و١٠، وفي كل مجال مربعات بنقاط ١٠ (سهل) و٢٠ (متوسط) و٣٠ (صعب).
- كل جولة ١٠ أسئلة تختارها الطالبة من اللوحة، وتُعطى الأولوية للأسئلة التي لم ترها أو أخطأت فيها سابقًا.
- ٣ مساعدات في كل جولة: حذف إجابتين، تلميح، محاولة ثانية.
- لكل سؤال وقت حسب صعوبته: ٣٠ ثانية للسهل، ٤٥ للمتوسط، ٦٠ للصعب. يظهر شريط الوقت ويتحول إلى الأحمر في آخر ٥ ثوانٍ، وعند انتهائه يُحسب السؤال خطأً وتظهر الإجابة الصحيحة.
- لا تُخصم نقاط عند الخطأ.
- تظهر مدة الجولة للطالبة في النتيجة، وللمعلمة في تفاصيل كل طالبة.
- **رحلة البطلة:** بعد كل جولة مكتملة تظهر كلمة تعزيز خاصة برقمها (الجولة الأولى، الثانية…) ونجوم من ١ إلى ٣ حسب الإجابات الصحيحة.
- شهادة «بطلة الجداول» تُمنح بعد إكمال ١٢ جولة (١٢ × ١٠ = ١٢٠ سؤالًا)، ويمكن حفظها صورة أو طباعتها.
- الجولة التي تُنهى قبل الأسئلة العشرة تُحسب نقاطها، لكنها لا تُحسب في رحلة البطلة.
- أربعة فرق بأسماء علماء رياضيات مسلمين، ونقاط الفريق = مجموع نقاط طالباته.
